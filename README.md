## The line

> Our printer only jams on urgent documents — I'm convinced it reads the file names.

One line about office life. The observation is true — the printer always jams on the document you need right now — and the turn is surprising: the machine is not broken, it is reading the file names and picking its moment.

## How it works

`main.ts` (Node 22, TypeScript run as-is) validates the line (1–199 characters, not only whitespace, single line) and writes it to `/output/entry.txt`. Run it with:

```sh
node main.ts
```

`OUTPUT_DIR` overrides the output directory (defaults to `/output`).
